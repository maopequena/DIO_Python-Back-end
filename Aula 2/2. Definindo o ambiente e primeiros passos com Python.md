## Vídeo 1 - Introdução ao Python

Objetivo geral: conhecer a história do Python e explorar as ideias de seu criador, e responder à pergunta: “Onde devo usar o Python?”.

O Python foi baseado na linguagem ABC, que era pensada para iniciantes, e os objetivos de seu criador eram:

- Ter uma linguagem fácil e intuitiva
- Ser de código aberto, para que todos possam contribuir
- O código deve ser tão inteligível quanto o inglês
- Deve ser adequado para tarefas diárias e deve ser produtiva.

 Onde se deve utilizar o Python?

O Python é uma linguagem muito dinâmica e versátil, tem tipagem dinâmica e forte, é multiplataforma e multiparadigma, tem uma comunidade ativa e gigante, e sua curva de aprendizado é baixa. Sua única desvantagem é que ele não é adequado para desenvolvimento *mobile*, no entanto há soluções para tal.
